Resistor choices

I used 100 ohm resistors in series with each LED. I calculated the red and green LEDs to need 150 ohm resistors and the blue LED to need an 85 ohm resistor. I did not have a 150 ohm or 85 ohm resistor, so I used a 100 ohm resistor, which still keeps the current within safe limits.

Code

//Establishes RED as the variable name for pin 13
int RED = 13;
//Establishes GREEN as the variable name for pin 12
int GREEN = 12;
//Establishes BLUE as the variable name for pin 8
int BLUE = 8;


//Code run only once when the arduino is first powered on
void setup() {
  //Establishes pin 13 (RED) as an output
  pinMode(RED, OUTPUT);
  //Establishes pin 12 (GREEN) as an output
  pinMode(GREEN, OUTPUT);
  //Establishes pin 8 (BLUE) as an output
  pinMode(BLUE, OUTPUT);
}


// the loop function runs over and over again forever while arduino is powered on
void loop() {
  // change state of the red LED to on by setting the pin to the HIGH voltage level
  digitalWrite(RED, HIGH);
  // change state of the blue LED to on by setting the pin to the HIGH voltage level
  digitalWrite(BLUE, HIGH);
  // change state of the green LED to on by setting the pin to the HIGH voltage level
  digitalWrite(GREEN, HIGH);
  //waits 1 second so all three LED appear lit for 1 second
  delay(1000);
  // change state of the blue LED to off by setting the pin to the LOW voltage level
  digitalWrite(BLUE, LOW);
  // change state of the green LED to off by setting the pin to the LOW voltage level
  digitalWrite(GREEN, LOW);
  //waits 1 second so only the red LED appears lit for 1 second
  delay(1000);
  // change state of the red LED to off by setting the pin to the LOW voltage level
  digitalWrite(RED, LOW);
  // change state of the green LED to on by setting the pin to the HIGH voltage level
  digitalWrite(GREEN, HIGH);
  //waits 1 second so only the green LED appears lit for 1 second
  delay(1000);
  // change state of the blue LED to on by setting the pin to the HIGH voltage level
  digitalWrite(BLUE, HIGH);
  // change state of the green LED to off by setting the pin to the LOW voltage level
  digitalWrite(GREEN, LOW);
  //waits 1 second so only the blue LED appears lit for 1 second
  delay(1000);
}
